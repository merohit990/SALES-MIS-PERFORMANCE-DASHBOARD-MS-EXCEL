# Sales MIS & Performance Dashboard — MS Excel

## Project Overview
An Excel-based MIS reporting project designed to track sales performance, targets, achievement percentage, regional performance and employee performance.

## Tools Used
- Microsoft Excel
- Pivot Tables / Pivot Charts
- XLOOKUP / VLOOKUP
- SUMIFS / COUNTIFS
- IF
- Conditional Formatting
- Data Cleaning & Validation
- Excel Dashboard

## Dataset
The project contains 120 synthetic sales records covering January–June 2026.

## Workbook Structure
1. **Raw Data** — transaction-level sales data
2. **MIS Summary** — region-wise sales and target
3. **Monthly Report** — monthly sales and target
4. **Employee Report** — employee-wise performance

## Key KPIs
- Total Sales
- Total Target
- Achievement %
- Region-wise Sales
- Monthly Sales Trend
- Top Performing Employees
